# University StudyHub (prototype)

A lightweight, web-based study resource and academic planning platform that a Kenyan public university can deploy for its own students, lecturers and administrators. It is organised by unit, with books and notes, assignments, quizzes and discussions inside each unit.

**Live demo:** https://github.com/19s01acs018-ux/university-studyhub.git

## Demo accounts

What it shows

- Role-based login and sign-up
- Unit cards with books, assignments (with submission), quizzes and discussions
- Task and deadline manager with priority, and a weekly study planner
- Timed quizzes with automatic marking
- Progress by unit, reports, and administrator student counts overall and per unit

## Notes

The prototype is a single HTML page with sample data. Entries are lost when the page is refreshed. The full system will use HTML, CSS and JavaScript with a PHP and MySQL backend.
